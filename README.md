# RelevoParking — descargas

Instaladores públicos para Windows x64. El código se mantiene en un repositorio privado separado. Esta página no contiene notas, bases de datos ni credenciales.

Las versiones marcadas como pruebas todavía no son una entrega de producción. La agenda funciona en un solo PC, sin cuentas y sin Internet durante el uso diario. Internet se usa para descargar actualizaciones.

Todavía no hay certificado de editor Windows: Windows/SmartScreen puede mostrar avisos de editor desconocido. Las actualizaciones dentro de la aplicación se verifican mediante un manifiesto Ed25519 firmado por el proyecto y el SHA-256 del paquete. Esa firma no equivale a Authenticode.

Usar únicamente los archivos de la sección Releases de este repositorio. Conservar copias verificadas fuera de la unidad de los datos antes de usar la aplicación con información operativa.
